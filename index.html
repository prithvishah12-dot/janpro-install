How to install

  1. 1

    Download the APK

    Tap the Download for Android button above. The file (~95 MB) will land in your Downloads folder.

  2. 2

    Open the file

    Tap the downloaded janpro.apk from your notifications drawer or Files app.

  3. 3

    Allow install from your browser

    If Android prompts, allow Install unknown apps for the browser you used to download. This is a one-time permission.

  4. 4

    Tap Install

    Sign in with the email address on file with the club. We will email you a 6-digit one-time code to verify.

Your data is encrypted in transit and at rest. Janpro never sells, shares, or markets on the back of member data.
